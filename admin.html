All image slots

Each slot controls every place that image appears on the site. Click Replace to upload a new image (goes to Cloudinary), Paste URL to use any URL, Delete file to permanently remove from Cloudinary, or Reset to revert to the default.

Web Projects

These projects appear in the Recent Web Work showcase on your site. Add, edit, delete, and reorder them. Changes appear instantly for all visitors. Use the search bar to filter, and checkboxes to mark multiple projects for bulk deletion.

—

Project Case Studies

Each case study powers a /project-detail.html?slug=SLUG page on the live site — the cover image, challenge, solution, tools, screenshots, and live-URL button. The first 3 entries are static defaults baked into site-config.js; anything you add here is saved to Firestore content/case-studies and shows up live.

Blog Posts

Each post powers a /blog-post.html?slug=SLUG page on the live site. The 3 default posts are baked into site-config.js; edits and new posts you create here are saved to Firestore content/blog-posts. Use the content editor for full HTML (paragraphs, headings, lists, links).

Downloadable Files

Three download slots surfaced on the public /downloads.html page: the CV, the corporate profile, and the brand deck. Upload a PDF (or paste a URL) to make a slot available; slots without a file show "Coming soon". Saved to Firestore content/downloads.

Site Content

Edit the homepage hero text, stat numbers, pricing tiers, testimonials, and the CTA band — all from one place. Changes are saved to Firestore content/site-content and applied to the live homepage on next load.

All text & captions

Every heading, label, title, and description on the site is editable here. Changes save automatically when you click Save (or press Enter). To add more, tag any element in index.html with data-text-slot="text:your-id".
